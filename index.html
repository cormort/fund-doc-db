工具定位

把散落文件轉成可保存、可整併、可查詢的結構化資料

本工具不是只做一次性的段落擷取，而是將 Word／PDF 中的基金內容轉為標準 JSON，形成可重複載入與持續累積的輕量化文件資料庫。

Word／PDF→解析結構→JSON 資料庫→跨文件查詢
1

建立資料

上傳一個或多個 Word／PDF，設定本批檔案的預算年度與基金屬性，再開始解析。

  • 辨識大標題、中標題及小標題
  • 將段落內容轉成一致的 JSON 結構
  • 解析完成後加入目前資料庫
2

管理資料庫

載入既有 JSON 資料庫，與目前資料合併，並排除相同年度、屬性、基金及來源檔案的重複資料。

  • 「載入 JSON 資料庫」用於接續既有資料
  • 「儲存 JSON 資料庫」用於備份目前完整資料
  • 關閉網頁前，請先儲存 JSON 資料庫
3

查詢與輸出

可依年度、基金名稱及標題階層逐層縮小範圍，也可使用關鍵字搜尋內容。

  • 查詢條件只篩選資料，不會修改資料
  • 關鍵字會在結果中醒目標示
  • 目前查詢結果可另行匯出為 Excel

資料角色說明

Word／PDF
原始文件來源，用來建立新的結構化資料。
JSON
資料庫的保存及交換格式，可跨批次載入、合併與備份。
目前資料庫
本次網頁已載入及建立的資料集合。資料主要存在瀏覽器記憶體中。
Excel
目前查詢結果的輸出格式，不是完整資料庫備份。
重要提醒：此版本是純瀏覽器工具，資料不會自動寫入伺服器。完成資料建置或整併後，請使用「儲存 JSON 資料庫」下載備份。
